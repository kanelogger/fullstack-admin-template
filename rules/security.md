# Security Rules

- 默认只加载当前需求所需的仓库文件、知识和工具。
- 密钥、`JWT_SECRET`、MySQL 口令、线上数据、客户信息和未脱敏敏感材料不得进入 Prompt、日志、提交物或交接产物；只引用变量名和 `.env.example` 中的占位写法。
- `.env*` 与 `uploads/` 已在 `.gitignore` 排除；发现敏感文件可被提交时先报告再处理。
- 外部系统写入、生产操作、发布和不可逆动作（删除数据、重置数据库、改写历史）必须获得人工批准。
- 鉴权链路（`requireAuth`、`WHITELIST`、Token 签发与刷新）属于高风险区域：改动前说明影响面，改动后按 `rules/testing.md` 真实验证未登录拦截与登录后访问。
- 发现权限范围与任务不匹配时停止执行，在当前任务中记录阻塞。

# tasks/

工作记忆：当前目标、进度、阻塞和下一步。每个进行中的需求一个文件，建议命名 `YYYYMMDD-<短名>.md`。
阶段、锁、缓存和本地证据放在被 `.gitignore` 排除的 `.agents/state/`；可合并、可审计的任务结论进入本目录或 `docs/adr/`。
建议结构：

```markdown
# <需求名>

- 状态：进行中 / 阻塞 / 已完成
- 目标：
- 下一步：
- 阻塞：
```

维护方式：随阶段更新；需求完成后把结论归档到 `docs/adr/`（如涉及取舍）并删除本任务文件，避免过期进度误导后续会话。

## 跨会话恢复

1. 先读本目录状态为“进行中”或“阻塞”的任务记录，恢复目标、验收条件、进度、阻塞和下一步；不能因本地状态缺失而跳过。
2. `.agents/state/workflow.json` 仅作本地提示；读取时按 [状态写入协议](../docs/agent-environment/network-filesystem.md) 核对归属。与任务记录冲突或指向已删除/已完成的任务时，以本目录为准，按协议更新提示；不继承旧会话的授权、锁或服务健康结论。
3. 有多个未完成任务时，按用户当前指示确定本次目标；指示不足则询问，不凭本地提示或时间戳擅自选择。
4. 没有未完成任务时，说明没有可恢复的任务记录；不要从旧本地状态重建任务。用户提出新需求时另建记录。

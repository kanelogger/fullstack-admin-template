# tasks/

工作记忆：当前目标、进度、阻塞和下一步。每个进行中的需求一个文件，建议命名 `YYYYMMDD-<短名>.md`。
阶段、锁、缓存和本地证据放在被 `.gitignore` 排除的 `.agents/state/`；可合并、可审计的任务结论进入本目录或 `docs/adr/`。
建议结构：

```markdown
# <需求名>

- 状态：进行中 / 阻塞 / 已完成
- 目标：
- 下一步：
- 阻塞：
```

维护方式：随阶段更新；需求完成后把结论归档到 `docs/adr/`（如涉及取舍）并删除本任务文件，避免过期进度误导后续会话。跨会话恢复时先看 `.agents/state/workflow.json`（存在时）和本目录。
